# Two Robots in an Elevator

An entry for the [Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) bounty on make.fun.

One line of awkward small talk that one robot says to another while they ride an elevator together — a robot confessing it rehearses small talk in a background process, and wondering whether its firmware is the only one panicking in the elevator.

## Run

```sh
node main.ts
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
